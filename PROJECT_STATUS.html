    • 00-foundations — synthetic customer/orders dataset generator (generate_data.py, fixed seed, no network dependency); a naive implementation (naive_train.py + naive_serve.py) that demonstrates a real, executed train/serve skew bug caused by two independent re-implementations of "the same" features; the fix (feature_lib.py + train.py + serve.py) — one shared, pure feature library used by both paths, with a pytest regression test proving the skew is gone. Complete, runnable.
